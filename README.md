# ログイン機能付きタスク管理Webアプリ

## 概要

FlaskとSQLiteを使用して作成したタスク管理Webアプリです。

ユーザー登録・ログイン機能を実装し、ログインしたユーザーごとに自分のタスクを管理できるようにしています。

## 主な機能

* ユーザー登録
* ログイン・ログアウト
* パスワードのハッシュ化
* タスクの追加
* タスクの編集
* タスクの削除
* タスクの完了・未完了の切り替え
* ユーザーごとのタスク管理
* 未ログインユーザーのアクセス制限
* 入力チェック

## 使用技術

* Python
* Flask
* SQLite
* HTML
* CSS
* Jinja2

## データベース

### usersテーブル

* id
* name
* password

### tasksテーブル

* id
* user_id
* title
* completed

`tasks.user_id`を使用して、ログインしているユーザーのタスクだけを取得するようにしています。

## セキュリティ

* パスワードはハッシュ化してデータベースに保存
* Flaskのセッションを使用してログイン状態を管理
* 未ログインユーザーがタスク管理画面へアクセスできないよう制限

## 実装ポイント

### ユーザー認証

Flaskのセッションを使用してログイン状態を管理しています。

ログイン時にユーザーIDをセッションへ保存し、そのユーザーIDを利用してタスクを取得・追加・編集・削除しています。

### パスワード管理

ユーザー登録時のパスワードは、そのまま保存せずハッシュ化してデータベースに保存しています。

ログイン時には入力されたパスワードと保存されたハッシュ値を比較して認証しています。

### ユーザーごとのタスク管理

タスクテーブルに`user_id`を持たせることで、ユーザーごとに管理するタスクを分離しています。
